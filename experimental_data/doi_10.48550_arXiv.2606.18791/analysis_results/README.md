# Standard-analysis results

The PNG files in this directory are generated by `../analyze_all.py` using
the common settings documented in the data set's main README. Running
`pixi run analyze-arxiv-2606-18791` overwrites the generated plots.

## Covariance-correction comparison

All four standard PNGs were regenerated with the corrected absolute-noise
covariance. The original fit configuration is unchanged.
The standard block-test panels show nominal model-based references without
Holm highlights. Holm probabilities remain supplementary numerical diagnostics.

The [combined comparison](../../README.md#covariance-correction-comparison)
reports changes of power error bars, radial error bands, and angular-block
statistics, including a separate Holm multiple-test check.
The reproducible scripts are
[compare_covariance.py](../../compare_covariance.py) and
[summarize_covariance.py](../../summarize_covariance.py).

For each field, [covariance_comparison/](covariance_comparison/) contains a
per-block CSV, a JSON summary with input/source hashes, and an old/new
comparison PNG. The precision_qr control separates factorization roundoff
from the geometric-weight correction.
