# Standard-analysis results

The PNG files in this directory are generated by `../analyze_all.py` using
the common settings documented in the data set's main README. Running
`pixi run analyze-prl-135-196706` overwrites the generated plots.

## Covariance-correction comparison

Both centered standard PNGs were regenerated with the corrected
absolute-noise covariance. The original fit and centering configurations
are unchanged. With unit sample weights, the covariances, error bars, and
block statistics agree with the previous formula to numerical precision.
The standard block-test panels show nominal model-based references without
Holm highlights. Holm probabilities remain supplementary numerical diagnostics.

The [combined comparison](../../README.md#covariance-correction-comparison)
includes both benchmarks. For each file,
[covariance_comparison/](covariance_comparison/) contains a per-block CSV,
a JSON summary with input/source hashes, and an old/new comparison PNG.
The scripts
[compare_covariance.py](../../compare_covariance.py) and
[summarize_covariance.py](../../summarize_covariance.py) reproduce the audit.
